# SK OTT

यह Flutter starter project है।

## चलाने के लिए
1. Flutter SDK install करें.
2. `flutter pub get`
3. `flutter run`

## मुख्य screens
Home, Search, Watchlist, Profile, Details और Video Player.

## अगला चरण
- Firebase login/database
- Admin panel
- अपनी licensed videos के लिए storage/CDN
- Subscription/payment
- Continue Watching
- Production security

Demo video और placeholder images केवल testing के लिए हैं। Production में अपने अधिकार वाले content और proper CDN/storage का उपयोग करें.
